# 🌾 Smart Agro (স্মার্ট এগ্রো) - Digital Agronomy Platform

> **বাংলাদেশের কৃষকদের জন্য প্রোডাকশন-রেডি এআই ক্রপ ডিজিজ স্ক্যানার, ৪০+ ফসলের চাষাবাদ রোডম্যাপ, কলম ও নার্সারি মাস্টারক্লাস, লাইভ জিপিএস আবহাওয়া সতর্কতা এবং দ্বৈত সার ক্যালকুলেটর প্ল্যাটফর্ম।**

---

## ⚡ মূল সক্ষমতা ও ফিচারসমূহ (Key Features)

### ১. এআই রোগ নির্ণয় স্ক্যানার (AI Crop Disease Diagnostic Engine)
- ক্যামেরা বা ফাইল আপলোড দিয়ে ধানের ব্লাস্ট, টমেটোর নাবি ধসা, আলুর মড়ক, বেগুনের ডগা ও ফল ছিদ্রকারী পোকা ইত্যাদি ৮টি প্রধান ফসলের রোগ তাৎক্ষণিক সনাক্তকরণ।
- ৩-স্তরের বিজ্ঞানসম্মত প্রেসক্রিপশন: লক্ষণ ও বিস্তার, জৈব ও পরিবেশবান্ধব প্রতিকার, এবং অনুমোদিত রাসায়নিক বালাইনাশক ও ব্যবহারের সঠিক মাত্রা।
- কৃষকের সুরক্ষার জন্য লাল সতর্কবার্তা (PPE, মাস্ক ও নিরাপদ সময় নির্দেশিকা)।
- বাংলা ভয়েস অ্যাসিস্ট্যান্ট (`SpeechSynthesis`) দিয়ে সম্পূর্ণ প্রেসক্রিপশন বাংলায় পাঠ করার সুবিধা।

### ২. ৪০+ ফসল ও ভ্যারাইটির আধুনিক চাষাবাদ রোডম্যাপ (Crop Roadmap Catalog)
- **দানা শস্য**: বোরো ধান, রোপা আমন ধান, উফশী আউশ ধান, সুগন্ধি ও পোলাও ধান, গম, ভুট্টা।
- **বাণিজ্যিক মাঠ সবজি**: আলু, টমেটো, গোল বেগুন, লম্বা শিংনাথ বেগুন, বারি বিটি বেগুন, সবুজ বেগুন, ফুলকপি, বাঁধাকপি, কচুর লতি।
- **উদ্যান ও ফলবাগান**: পেঁপে, উন্নত জাতের পেয়ারা, কাগজি ও সিডলেস লেবু, উন্নত জাতের আম, ড্রাগন ফল, বারি মাল্টা-১।
- **মাচার লতানো সবজি**: লাউ, মিষ্টি কুমড়া, শসা, করলা ও উচ্ছে, পটল, শিম, চিচিঙ্গা, ঝিঙা, চাল কুমড়া, ঢেঁড়শ।
- **মসলা, ডাল ও তৈলবীজ**: পেঁয়াজ, রসুন, আদা, হলুদ, সরিষা, মসুর ডাল।
- **শাকসবজি**: লালশাক, পালং শাক, ডাঁটা শাক, পুঁইশাক, কলমি শাক।
- প্রতিটি ফসলের জন্য ৫টি পূর্ণাঙ্গ ধাপ (মাটি প্রস্তুতি, বীজ শোধন, সার ব্যবস্থাপনা, ফসল কর্তন, সংরক্ষণ), আসল ৪-স্টেজের ফটো গ্যালারি (ফসল, বীজ, চারা, সংগ্রহ), এবং অভিজ্ঞ কৃষিবিদদের প্র্যাকটিক্যাল ইউটিউব ভিডিও।
- **৮ মিমি স্লিম প্রিন্টিং মার্জিন**: ব্রাউজারে প্রিন্ট চাপলে শুধুমাত্র নির্বাচিত ফসলের প্রিন্টেবল নির্দেশিকা প্রিন্ট হবে।

### ৩. কলম ও নার্সারি মাস্টারক্লাস (Grafting & Nursery Simulator)
- ৫-ফেজ ইন্টারঅ্যাক্টিভ ভার্চুয়াল এসভিজি সিমুলেটর (রুটস্টক কাট, সায়ন ওয়েজ তৈরি, ক্যাম্বিয়াম লেয়ার অ্যালাইনমেন্ট, ক্লিপ/পলি-র‍্যাপ বাঁধন, এবং আর্দ্রতা হিলিং চেম্বার)।
- উদ্ভিদের সুনির্দিষ্ট কলম মেথড: টমেটো ও বেগুনের ক্লেফট গ্রাফটিং, পেয়ারার গুটি কলম, লেবুর গুটি কলম, আমের ভিনিয়ার ও এপিকোটাইল কলম, এবং বয়োবৃদ্ধ গাছের টপ ওয়ার্কিং।

### ৪. সুষম সার ক্যালকুলেটর: দ্বৈত হিসাব মোড (Dual Mode Fertilizer Engine)
- **মোড ১ (জমির ক্ষেত্রফল অনুযায়ী)**: শতাংশ, কাঠা, বিঘা বা একর জমিতে মোট কত কেজি ইউরিয়া, টিএসপি, এমওপি, জিপসাম, জিংক, বোরন ও জৈব সার লাগবে তার BARC স্ট্যান্ডার্ড হিসাব। একই সাথে জমিতে সম্ভাব্য চারা সংখ্যা ও চারা প্রতি সার হিসাব।
- **মোড ২ (চারা বা গাছ সংখ্যা অনুযায়ী)**: ফলবাগান বা রোপণকৃত সবজির জন্য চারার সংখ্যা (যেমন: ৫০টি পেঁপে গাছ, ৫০০টি টমেটো চারা, ৩০টি লাউয়ের মাদা) অনুযায়ী গাছপ্রতি সুনির্দিষ্ট গ্রাম হিসাব (Dose per plant) এবং মোট চারার জন্য মোট সারের সমন্বিত তালিকা ও রিং পদ্ধতিতে প্রয়োগ নির্দেশিকা।

### ৫. গতি ও পারফরম্যান্স অপ্টিমাইজেশন (Speed & Asset Compression)
- প্রজেক্টের ২০০+ হাই-রেজুলেশন ইমেজকে পাইথন পিলো (Pillow) ল্যানকজোস অ্যালগরিদমে অপ্টিমাইজ করায় মোট অ্যাসেট সাইজ ৪৫০ মেগাবাইট থেকে কমে মাত্র ২২ মেগাবাইটে নেমে এসেছে (৯৫% সাইজ হ্রাস)।
- এক্সপ্রেস সার্ভারে `compression()` মিডলওয়্যার ব্যবহারের মাধ্যমে সকল HTML, JSON API ও স্ট্যাটিক অ্যাসেট Gzip কম্প্রেশনে পরিবাহিত হয়।
- ১ দিনের ব্রাউজার ক্যাশিং ও <code>loading="lazy"</code> ব্যবহারের ফলে সম্পূর্ণ সাইট ৩জি নেটওয়ার্কেও চোখের পলকে লোড হয়।

## 🚀 কুইক স্টার্ট ও রান কমান্ড (Quickstart)

```bash
# ১. ডিপেনডেন্সি ইনস্টল করুন
npm install

# ২. সার্ভার চালু করুন (Port 3000)
npm start

# ৩. স্বয়ংক্রিয় টেস্ট স্যুট রান করুন (১৪৫টি পরীক্ষা)
npm test
# অথবা: node scripts/tests/verify-smart-agro.js

# ৪. ৩টি ডকুমেন্টেশন PDF ম্যানুয়াল জেনারেট/আপডেট করতে
npm run docs
# অথবা: node scripts/generators/generate-docs.js
```

ব্রাউজারে ওপেন করুন:
- **মূল ড্যাশবোর্ড**: [http://localhost:3000](http://localhost:3000)
- **চাষাবাদ রোডম্যাপ**: [http://localhost:3000/roadmap](http://localhost:3000/roadmap)
- **কলম মাস্টারক্লাস**: [http://localhost:3000/grafting](http://localhost:3000/grafting)
- **সার ক্যালকুলেটর**: [http://localhost:3000/calculator](http://localhost:3000/calculator)
- **লোকাল ডেভেলপার ম্যানুয়াল**: [http://localhost:3000/docs/guide](http://localhost:3000/docs/guide)
- **লোকাল এআই মডেল গাইড**: [http://localhost:3000/docs/ai-model](http://localhost:3000/docs/ai-model)
- **লোকাল ডিপ্লয়মেন্ট গাইড**: [http://localhost:3000/docs/deployment](http://localhost:3000/docs/deployment)

## 🛠️ ভবিষ্যতে পরিবর্তন বা সম্পাদনা করার নিয়ম (How to Edit)

| কাজের ক্ষেত্র | যে ফাইল বা ফোল্ডারে পরিবর্তন করবেন |
|---|---|
| **রোডম্যাপে নতুন ফসল বা জাত যোগ** | `data/cropGuidesData.js` এবং ছবিগুলো `public/images/` ফোল্ডারে রাখুন |
| **সারের মাত্রা বা চারা/গাছপ্রতি হিসাব পরিবর্তন** | `data/plantFertilizerSpecs.js` এবং `server.js` |
| **এআই স্ক্যানারের রোগ, লক্ষণ বা বালাইনাশক প্রেসক্রিপশন** | `server.js` ফাইলের `diseaseDatabase` অবজেক্ট |
| **কলম মেথড বা ভার্চুয়াল অ্যানিমেশন পরিবর্তন** | `public/grafting.html` এবং `public/js/grafting.js` |
| **ডিজাইন, কালার বা গ্লাস মরফিজম পরিবর্তন** | `public/css/style.css` |
| **ডাটাবেস টেবিল ও স্কিমা আপডেট** | `schema.sql` এবং `db.js` |
| **PDF ডেভেলপার গাইড আপডেট** | টার্মিনালে চালান: `npm run docs` |

স্মার্ট এগ্রো (Smart Agro)

ক্লাউড ডেপ্লয়মেন্ট, হোস্টিং ও প্রোডাকশন পরিচালনা ম্যানুয়াল

ডকুমেন্ট কোড: SAG-DEP-2026

ভার্সন: 2.5.0 Production Ready

ক্যাটাগরি: DevOps, Cloud Hosting & Security

🌐 হোস্টিং পরিচিতি ও মূল বিষয়বস্তু

স্মার্ট এগ্রো প্ল্যাটফর্মটি প্রোডাকশনে হোস্ট করার জন্য ৩টি নির্ভরযোগ্য পথ রয়েছে: Render / Railway (ফ্রি ও সহজতম ক্লাউড PaaS), Google Cloud Run (সার্ভারলেস ডকার কন্টেইনার) এবং স্বয়ংসম্পূর্ণ লিনাক্স VPS (Ubuntu + Nginx + PM2 + SSL)। এই গাইডে ডোমেন সেটআপ থেকে শুরু করে ডাটাবেস মাইগ্রেশন ও সার্বক্ষণিক সার্ভার মনিটরিং পর্যন্ত সবকিছু বিশদভাবে নির্দেশ করা হয়েছে।

১. ডেপ্লয়মেন্ট প্রি-ফ্লাইট চেকলিস্ট ও এনভায়রনমেন্ট ভেরিয়েবলস

প্রোডাকশন সার্ভারে তোলার পূর্বে নিশ্চিত করুন যে নিচের এনভায়রনমেন্ট ভেরিয়েবলগুলো কনফিগার করা আছে:

ভেরিয়েবল নাম প্রয়োজনীয়তা ডিফল্ট মান বিবরণ ও উদাহরণ
PORT ঐচ্ছিক 3000 যে পোর্টে এক্সপ্রেস ওয়েব সার্ভারটি রান করবে।
NODE_ENV বাধ্যতামূলক production পারফরম্যান্স অপ্টিমাইজেশন ও ক্যাশিং সক্রিয় করতে।
DATABASE_URL প্রস্তাবিত ইন-মেমোরি PostgreSQL ডাটাবেসের ফুল কানেকশন স্ট্রিং।
OPENWEATHER_API_KEY ঐচ্ছিক ফলব্যাক মডেল লাইভ আবহাওয়ার জন্য ওপেনওয়েদার এপিআই কি।

২. অপশন ১: Render.com এ ১-ক্লিকে ডেপ্লয় (সবচেয়ে সহজ ও ঝামেলামুক্ত)

প্রজেক্টের রুটে পূর্ব থেকেই একটি প্রোডাকশন-রেডি ব্লুপ্রিন্ট render.yaml দেওয়া আছে।

ধাপ ১: কোড GitHub-এ পুশ করুন

git init && git add . && git commit -m "Production ready" && git push origin main

ধাপ ২: Render ড্যাশবোর্ডে ব্লুপ্রিন্ট কানেক্ট করুন

১. dashboard.render.com এ লগইন করুন।
২. New > Blueprint এ ক্লিক করে আপনার রিপোজিটরিটি সিলেক্ট করুন।
৩. Render স্বয়ংক্রিয়ভাবে Node.js ওয়েব সার্ভিস ও Managed PostgreSQL তৈরি করে লাইভ URL দেবে।

ধাপ ৩: ডেটাবেস স্কিমা এক্সিকিউট করুন

Render PostgreSQL-এর Shell ট্যাবে গিয়ে প্রজেক্টের schema.sql ফাইলের কুয়েরি রান করলেই সকল টেবিল তৈরি হয়ে যাবে।

৩. অপশন ২: উবুন্টু VPS ডেপ্লয়মেন্ট (Ubuntu 22.04 / 24.04 LTS)

সম্পূর্ণ নিয়ন্ত্রণ, সর্বোচ্চ গতি ও স্বল্প খরচে বড় ট্রাফিক সামলাতে একটি ভিপিএস (DigitalOcean, Hetzner, AWS EC2, বা দেশীয় হোস্টিং) ব্যবহার করুন।

ক. সার্ভার আপডেট ও Node.js ইনস্টলেশন:

sudo apt update && sudo apt upgrade -y
# Node.js 20 LTS ইনস্টল করুন
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs git nginx ufw

খ. প্রজেক্ট সেটআপ ও PM2 দিয়ে সার্ভার ব্যাকগ্রাউন্ডে চালানো:

# কোড ক্লোন ও ডিপেন্ডেন্সি ইনস্টল
git clone <your-repo-url> /var/www/smart-agro
cd /var/www/smart-agro
npm install --production

# গ্লোবাল প্রসেস ম্যানেজার PM2 ইনস্টল
sudo npm install -g pm2

# ক্লাস্টার মোডে সার্ভার স্টার্ট
pm2 start server.js -i max --name "smart-agro"
pm2 save
pm2 startup

গ. Nginx রিভার্স প্রক্সি কনফিগারেশন (/etc/nginx/sites-available/smart-agro):

server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;

    client_max_body_size 25M;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}

ঘ. Nginx সক্রিয়করণ ও ফ্রি SSL সার্টিফিকেট (Let's Encrypt HTTPS):

sudo ln -s /etc/nginx/sites-available/smart-agro /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# Certbot দিয়ে লাইফটাইম ফ্রি অটো-রিনিউয়িং SSL নিন
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com

৪. কাস্টম ডোমেন ও ডিএনএস সেটআপ (.com বা .com.bd ডোমেন)

ডোমেন প্রোভাইডার (যেমন: BTCL, Namecheap, GoDaddy, বা Cloudflare)-এর DNS Management প্যানেলে গিয়ে নিচের দুটি রেকর্ড যুক্ত করুন:

রেকর্ড টাইপ হোস্ট / নেম টার্গেট / ভ্যালু TTL
A Record @ (রুট) আপনার সার্ভারের পাবলিক আইপি (যেমন: 159.65.12.34) Automatic / 300s
CNAME www yourdomain.com. Automatic / 300s

৫. ডেটাবেস অটোমেটেড ব্যাকআপ ও মেইনটেনেন্স

কৃষকদের রোগ নির্ণয় রেকর্ড ও ডেটা সুরক্ষার জন্য প্রতিদিন মধ্যরাতে স্বয়ংক্রিয় ব্যাকআপ নিতে নিচের ক্রনজবটি সেট করুন: 

# ক্রনজব ওপেন করুন
crontab -e

# প্রতিদিন রাত ২:০০ টায় অটোমেটিক ব্যাকআপ ফাইল সংরক্ষণ করুন
0 2 * * * pg_dump -U postgres smart_agro > /var/backups/smart_agro_$(date +\%F).sql
